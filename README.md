# pywriter
This program imitates work of typewriter. It has 2 versions:
- Python
- C

It has no difference between each other but I want to learn C so why not
# Usage
For each version syntax is the same:
`python pywriter.py <filename>`
>If you want to change the speed of writing you should add `-s <value>` flag. Lower value mean faster typing speed.
`python pywriter.py -s <value> <filename>`

Final command will look like `python pywriter.py -s 0.3 file.txt`
